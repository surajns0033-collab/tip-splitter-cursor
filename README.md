# Tip Splitter

A tiny tip calculator + bill splitter built for **MLH Global Hack Week: Open Source — Challenge 1: Build a Mini App with Cursor**.

## Features

- Enter a bill amount, pick a tip % (preset or custom)
- Split the total between any number of people
- Live results: tip, total, and per-person share
- Dark / light mode toggle (remembers your choice)
- Input validation with inline error messages

## Run it

No build step. Just open `index.html` in a browser:

```
start index.html
```

## Built with Cursor

Cursor scaffolded the whole app (HTML, CSS, JS) from a one-line description and then iterated on it — adding the custom tip input, the people +/− stepper, dark mode with `localStorage` persistence, and input validation.
